# Model Placeholder

Put local model artifacts here when running the code.

This folder is intentionally empty in the submitted package because checkpoints
and ONNX files are large. The exact file names are not fixed; pass the paths to
the scripts through arguments such as:

- `--phase1-pretrained-path`
- `--phase2-pretrained-path`
- `--model-path`
- `--clip-onnx-model`
- `--onnx-model`
